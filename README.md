# Almas Gêmeas — convite digital

Site estático responsivo para o lançamento de **Almas Gêmeas** e celebração dos 28 anos de casamento de Jorge e Ariela.

## Arquivos
- `index.html` — estrutura e conteúdo
- `styles.css` — identidade visual e responsividade
- `script.js` — animações, menu e formulário/WhatsApp
- `assets/jorge-ariela.jpeg` — fotografia fornecida
- `assets/capa-almas-gemeas.jpeg` — capa fornecida

## Publicação
Pode ser publicado diretamente no GitHub Pages:
1. Crie um repositório.
2. Envie todos os arquivos mantendo a pasta `assets`.
3. Em **Settings → Pages**, selecione a branch principal e a pasta `/root`.
4. O GitHub Pages publicará o `index.html`.

## Observação sobre RSVP
Não existe backend. O formulário apenas valida os campos, monta a mensagem e abre o WhatsApp `+55 61 99652-9417`. A confirmação só acontece quando o convidado envia a mensagem no WhatsApp.

## Conteúdo
A sinopse foi preservada integralmente conforme o texto fornecido. Não foram inventados preços, disponibilidade de exemplares, depoimentos ou fatos biográficos.


### Música ambiente
O site inclui uma trilha instrumental romântica leve sintetizada pelo navegador via Web Audio API. Por restrições de autoplay dos navegadores, o visitante ativa/desativa a música pelo botão no topo; nenhum arquivo de áudio externo é necessário.


A celebração de 28 anos é apresentada como **Bodas de Hematita**.
